# Hashing

Hashing is a technique used to store and retrieve data efficiently using a **hash function** and a **hash table**.

This implementation demonstrates hashing using **Linear Probing**, which is a collision resolution technique based on open addressing.

## Hash Function

The hash function used in this implementation is:

```text
h(key) = key % TABLE_SIZE
```

For a table size of `10`:

```text
h(25) = 25 % 10 = 5
h(35) = 35 % 10 = 5
h(45) = 45 % 10 = 5
```

Therefore, `25`, `35`, and `45` produce the same index.

This situation is called a **collision**.

---

## Collision Resolution: Linear Probing

When the calculated index is already occupied, Linear Probing checks the next position.

The formula is:

```text
h_i(key) = (h(key) + i) % TABLE_SIZE
```

For example:

```text
25 % 10 = 5
```

So `25` is stored at index `5`.

Now insert `35`:

```text
35 % 10 = 5
```

Index `5` is already occupied.

Therefore, we check:

```text
Index 5 → occupied
Index 6 → empty
```

So `35` is stored at index `6`.

Now insert `45`:

```text
45 % 10 = 5
```

Index `5` → occupied
Index `6` → occupied
Index `7` → empty

Therefore, `45` is stored at index `7`.

The table becomes:

```text
Index    Value
0        EMPTY
1        EMPTY
2        EMPTY
3        EMPTY
4        EMPTY
5        25
6        35
7        45
8        EMPTY
9        EMPTY
```

## Example

The program inserts:


### Hash calculations

```text
25 % 10 = 5
35 % 10 = 5
45 % 10 = 5
12 % 10 = 2
22 % 10 = 2
```

Because multiple keys generate the same index, Linear Probing is used to resolve the collisions.

## Operations

### 1. Insertion

The `insert()` function:

1. Calculates the hash index.
2. Checks whether the position is empty.
3. If occupied, moves to the next position.
4. Continues until an empty position is found.
5. Stores the key.

### 2. Searching

The `search()` function:

1. Calculates the original hash index.
2. Checks the current position.
3. If the key is not found, checks the next position.
4. Continues until the key is found or the search completes.

### 3. Display

The `display()` function prints every index and its stored value.

---

## Important Terms

### Hash Table

A data structure used to store keys according to indexes generated by a hash function.

### Hash Function

A function that converts a key into an index.

### Collision

A collision occurs when two or more different keys generate the same hash index.

### Linear Probing

A collision resolution technique in which the next available position is searched sequentially.
